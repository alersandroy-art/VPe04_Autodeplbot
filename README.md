# API времени

Простой тестовый бэкенд на [FastAPI](https://fastapi.tiangolo.com/), который возвращает текущее время сервера в формате UTC.

## Возможности

- Корневой эндпоинт с краткой информацией об API
- Эндпоинт `/time` с текущим временем сервера
- Автоматическая документация Swagger UI (`/docs`)
- Запуск через `python main.py` или `uvicorn`
- Настройка хоста, порта и режима отладки через переменные окружения

## Требования

- Python 3.10+

## Запуск

### Способ 1: через Python

```powershell
python main.py
```

### Способ 2: через Uvicorn

```powershell
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

После запуска приложение доступно по адресу: http://127.0.0.1:8000

## Переменные окружения

Используются при запуске `python main.py`:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `HOST`     | `0.0.0.0`    | Адрес, на котором слушает сервер |
| `PORT`     | `8000`       | Порт сервера |
| `DEBUG`    | `False`      | При значении `true` включается автоперезагрузка при изменении кода |

Пример с отладкой:

```powershell
$env:HOST="127.0.0.1"
$env:PORT="8080"
$env:DEBUG="true"
python main.py
```

## API

### `GET /`

Краткая информация об API.

**Пример ответа:**

```json
{
  "message": "API времени",
  "docs": "/docs"
}
```

### `GET /time`

Текущее время сервера (UTC).

**Пример ответа:**

```json
{
  "utc": "2026-05-17T14:27:17.021134+00:00",
  "timestamp": 1779028037.021134
}
```

| Поле        | Описание |
|-------------|----------|
| `utc`       | Время в формате ISO 8601 (UTC) |
| `timestamp` | Unix-время в секундах |
